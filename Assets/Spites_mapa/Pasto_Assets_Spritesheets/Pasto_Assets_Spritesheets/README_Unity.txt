PASTO ANIMADO - SPRITESHEETS

Cada carpeta contiene un spritesheet horizontal de 4 frames.
Tamaño de cada frame: 48x48 px.
Tamaño de cada spritesheet: 192x48 px.

Estilos:
01 - Pasto clásico
02 - Pasto con flores
03 - Pasto alto
04 - Pasto con hojas caídas
05 - Pasto con viento
06 - Pasto con detalles de tierra
07 - Pasto con mariposas
08 - Pasto con sombras
09 - Pasto con brillos

UNITY
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Pixels Per Unit: 48
- Filter Mode: Point (no filter)
- Compression: None
- Slice: Grid by Cell Size -> 48 x 48

Después puedes usar los 4 sprites como frames de una animación.
